# 四人分工（一页看完）

**一句话**：12 个指标，每人做 3 个，各写 3 条 SQL，传到同一个 GitHub 仓库，组长最后合起来。

## 分工（就这一张表）

| 谁 | 做哪 3 个 | 说人话就是 |
|---|---|---|
| **组长** | 01 日均刷卡量、02 高峰小时系数、08 早晚高峰客流比 | 一天多少人、几点最挤、早上人多还是晚上人多 |
| **组员 1** | 03 各线路日均客流、04 各站点日均客流、07 客流空间集中度 | 哪条线、哪个站人最多 |
| **组员 2** | 05 工作日/周末客流比、06 节假日客流变化率、09 月度客流趋势斜率 | 平时和假期差多少、客流有没有逐月变多 |
| **组员 3** | 10 站点进出比、11 工作日客流稳定性、12 累计计数异常率 | 站点是住人的还是上班的、客流稳不稳、数据有没有错 |

为什么这么分：同一组算的是同一类东西，三个人可以互相抄；四个人改四个不同的文件，不会撞车。

## 组长多做的 2 件事

1. 建一个 GitHub 仓库叫 `city-bus-flow-analysis`，把数据文件和一个结果样例放进去，再把 3 个组员加进来
2. 最后把 4 份结果拼成一张表和一个展示页面

## 全组只要记住 3 条

1. **同一个数据**：都用组长放进仓库的那份数据，谁都不许自己换
2. **同一种写法**：都用 Hive 写 SQL，连组长那一套环境，一人一个 `.sql` 文件
3. **同一种结果**：每人交一个 CSV，**照组长放进去的样例抄格式**就行

## 每人交什么

- 1 个 `.sql` 文件（里面 3 条 SQL，每条上面写一句中文说明这题在算什么）
- 1 个结果 CSV
- 传到 GitHub 一次

就这些，没有别的任务。

## 顺序

组长建仓库 → 4 个人同时做自己的 3 个 → 组长合起来 → 交作业
